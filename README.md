# Anexos-Trabajo-de-titulo-Graficos-de-Corriente

# 📈 Directorio de Gráficos de Corriente

En esta rama se almacenan los gráficos exportados que documentan los perfiles de corriente de las simulaciones dinámicas. Los resultados permiten analizar el comportamiento transitorio de la red frente a distintas perturbaciones.

## 📌 Nomenclatura de Archivos

Los archivos están estructurados numéricamente para reflejar el progreso de la investigación y las comparativas entre los distintos modelos:

* **Primer dígito (Sistema y Técnica):**
    * `1.x`: Red de Prueba (Simulación EMT)
    * `2.x`: Red SEN Académico - Variación de Carga (Simulación EMT)
    * `3.x`: Red SEN Académico - Cortocircuito (Simulación EMT)
    * `4.x`: Red de Prueba (Simulación RMS)
    * `5.x`: Red SEN Académico - Variación de Carga (Simulación RMS)
    * `6.x`: Red SEN Académico - Cortocircuito (Simulación RMS)
* **Segundo dígito (Escenario de Reemplazo):**
    * En la Red SEN, los sufijos del `.1` al `.5` indican el porcentaje de penetración (Caso Base, 25%, 50%, 75% y 100% respectivamente).
