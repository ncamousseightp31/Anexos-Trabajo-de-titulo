# 📈 Perfiles de Corriente: Simulaciones EMT y RMS

Esta rama almacena las gráficas resultantes de las simulaciones dinámicas. Las imágenes documentan la respuesta transitoria de la corriente ante eventos de variación de carga y cortocircuito.

El orden de los archivos presentados a continuación sigue la misma estructura y nomenclatura detallada en el documento principal de la memoria, evaluando distintos escenarios de reemplazo de generación síncrona.
